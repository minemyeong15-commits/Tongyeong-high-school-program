# 통영고 생활지원센터

학교용 분실물·교복 대여·예상 질문 웹앱의 첫 번째 프로토타입입니다.

## 현재 구현된 기능

- 학교 마크 표시
- 분실물 목록 확인
- 사진을 찍거나 선택해 분실물 등록
- 습득 장소/날짜/등록자 입력
- 교복 종류·사이즈·재고 확인
- 교복 대여 신청
- 예상 질문 검색 및 답변
- 브라우저 `localStorage`를 이용한 데모 데이터 저장

## 중요한 점

현재 버전은 **GitHub Pages에서 바로 실행할 수 있는 프론트엔드 프로토타입**입니다.
따라서 학생 A가 등록한 분실물을 학생 B의 컴퓨터에서 자동으로 볼 수는 없습니다.

실제 학교 서비스로 운영하려면 다음 단계에서 Firebase 또는 Supabase를 연결하면 됩니다.

### 추천 개발 순서

1. GitHub 저장소에 이 폴더 업로드
2. GitHub Pages로 웹사이트 공개
3. Firebase/Supabase 데이터베이스 연결
4. 사진 저장소 연결
5. 학생/교직원 로그인 추가
6. 교사 관리자 화면 추가
7. 분실물 승인/삭제 및 교복 대여 승인 기능 추가

## GitHub Pages

GitHub 저장소의 `Settings → Pages`에서 배포 소스를 설정하면 됩니다.
보통 `Deploy from a branch` → `main` → `/ (root)`를 선택합니다.

## 주의

실제 학교 서비스에서는 학생 이름, 사진 등의 개인정보를 다룰 수 있으므로
학교의 개인정보 보호 지침과 담당 교사의 승인을 먼저 확인해야 합니다.
